# Day 01: Personal Digital Business Card

**Difficulty:** Level 1 (Easy)

## 🎯 Learning Objective
Build a single-page personal profile card that presents who you are, what you do, and how to contact you. Practice semantic HTML structure, basic CSS box-model styling, and a tiny JavaScript DOM query setup.

## 📐 Visual & Functional Spec
- Create a centered card on the page using a fixed width, background color, border, padding, and rounded corners.
- Add a profile image or simple avatar area, name, title, short bio, and contact links.
- Use clean typography and spacing so the content reads clearly.
- Include at least one visible action element such as a button, email link, or portfolio link.
- Keep the design neat and readable with `margin: 0 auto` and `text-align` for alignment.
- Make sure the page feels like a polished digital business card instead of a generic text block.

## 📝 Step-by-Step Micro-Tasks

### Task 1: HTML Markup Foundation
- Use semantic HTML elements to structure the card: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<main>`, `<header>`, `<section>`, `<h1>`, `<p>`, `<a>`, `<img>`, and `<footer>`.
- Create a container for the business card with a profile image or avatar area, your name, job title, short description, and contact links.
- Keep the elements organized in a clear document flow so the content is easy to style later.

### Task 2: CSS Visual Styling & Layout
- Set a width for the card and center it on the page using `margin: 0 auto`.
- Apply `padding`, `border`, `border-radius`, `background-color`, `color`, `font-family`, `text-align`, and `max-width` to shape the card.
- Style the headings, paragraphs, links, and image so the card feels neat and readable.
- Use the box model to control spacing, borders, and visual hierarchy without relying on advanced layout techniques.

### Task 3: JavaScript Interactivity & Logic
- Use `document.querySelector()` to select at least one element from the page.
- Add a simple interaction such as a click on a button or link to demonstrate DOM selection.
- Keep the logic simple and focused on your card content, such as changing text or confirming a user action.

### Task 4: Final Mini-Project Integration
- Connect the HTML, CSS, and JavaScript together into one complete digital business card.
- Check that the card is centered, the content is readable, and all links or buttons behave as expected.
- Verify the page loads cleanly and that no JavaScript errors appear in the browser console.

## ✅ Acceptance Criteria Checklist
- [ ] The page contains a clear semantic structure with a main card layout.
- [ ] The business card includes a name, role, short bio, and contact information.
- [ ] The card is centered on the page using `margin: 0 auto` and readable spacing.
- [ ] CSS uses box-model properties such as `padding`, `border`, `border-radius`, and `background-color`.
- [ ] At least one element is selected with `document.querySelector()` in JavaScript.
- [ ] The final page feels polished, clean, and suitable as a digital business card.
